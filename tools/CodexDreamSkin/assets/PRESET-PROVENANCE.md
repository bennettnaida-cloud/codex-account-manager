# Preset provenance

The two current upstream preset packs in this bundle were copied from
`Fei-Away/Codex-Dream-Skin` commit
`3af1d6d62f3a0388cc640d2f497ac3100998938e` for this user's local installation.

Local-to-upstream file mapping:

- `presets/preset-arina-hashimoto/background.jpg` and the flat runtime copy
  `presets/preset-arina-hashimoto.jpg` map to
  `macos/presets/preset-arina-hashimoto/background.jpg`.
- `presets/preset-arina-hashimoto-preview.jpg` maps to
  `docs/images/presets/arina-hashimoto-light.jpg` and is used only as an
  Account Manager preview, never as a wallpaper.
- `presets/preset-gothic-void-crusade/background.jpg` and the flat runtime copy
  `presets/preset-gothic-void-crusade.jpg` map to
  `macos/presets/preset-gothic-void-crusade/background.jpg`.
- `presets/preset-gothic-void-crusade-preview.jpg` maps to
  `docs/images/presets/gothic-void-crusade-preview.jpg` and is used only as an
  Account Manager preview, never as a wallpaper.
