Codex Account Manager 一键安装版
================================

安装方法
--------
1. 先完整解压本压缩包，不要直接在压缩软件预览窗口中运行。
2. 双击“一键安装 Codex Account Manager.cmd”。
3. 安装完成后软件会自动打开，桌面和开始菜单也会生成快捷方式。
双击后会立即出现蓝色进度窗口，成功或失败都会弹出中文结果框。
日志默认保存在 %LOCALAPPDATA%\CodexAccountManager\InstallerLogs，结果框会显示完整日志路径。

程序为个人构建、未购买商业代码签名证书，Windows 首次运行时可能显示 SmartScreen。
请先核对压缩包的 SHA-256；确认文件来自分享者且哈希一致后，再选择“更多信息 → 仍要运行”。

默认安装目录
------------
%LOCALAPPDATA%\Programs\CodexAccountManager

主程序为自包含的 Windows x64 单文件，安装和运行都不需要另外安装 .NET 10。
安装不需要管理员权限，不会修改系统级文件。以后拿到新版时，直接再次运行新版
安装包即可覆盖升级；已有账号列表、设置、额度记录不会被安装程序覆盖。
首次按 1038×615 居中打开，之后会记住你最后关闭时的窗口大小和位置。

首次使用
--------
1. 点击“新增账号”。
2. 每个账号使用单独的凭据目录，避免互相覆盖。
3. 每张账号卡都有“Codex++ 启动”和“Codex 启动”两个按钮。电脑没有安装
   Codex++ 时，直接选择官方 Codex 即可；软件同时内置 Windows x64 Codex CLI。
4. Codex++ 启动会快速返回并在后台等待增强桥接，同时隐藏 Codex++ 管理中间窗。
   首次冷启动仍可能受 Windows 更新、杀毒扫描和电脑性能影响。

API Key 与 Access Token 账号都采用一键凭据投放：点击启动时，管理器会把所选账号自己的
API Key 或 PAT 写成官方 Codex App 可识别的 auth_mode=apikey 登录文件，无需在 App 内
重复输入密钥。Access Token 的模型请求仍由本机 PAT 网关转发并使用该账号的月额度；
已有 ChatGPT OAuth 会先备份，但不是启动前置条件。

“系统配置”中的代理地址和端口可分别编辑，地址默认 127.0.0.1。“自动检测”只探测本机
回环地址，并显示、回填和保存检测到的 HTTP 代理端口；以后更换代理软件时也可手动修改。

额度与用量
----------
额度页面显示本地 Token 用量、官方百分比和重置时间。额度推断需要在详情页手动开启；
每次开启都从点击时刻建立新的监测周期，关闭后停止更新，再次开启不会沿用旧周期判断。
监测只依据新周期内的自然使用历史被动推断 API 等值总额度和剩余额度。软件不提供主动
额度探针，不发送测试提示、不进行压力测试，也不会轮询或登录其它账号。启动当前套餐
账号后的额度刷新和“查询重置次数”均为单次只读请求，不消耗模型 Token。

有 5h 窗口的周额度账号按 5h 主窗口判断，正常参考阈值为 10 美元；只有周窗口的账号
按周窗口判断，阈值为 90 美元；月额度账号按最近有效窗口的主模型判断，Sol、Terra、
Luna 的阈值分别为 200、100、80 美元，未知模型回退到 200 美元。监测采用重叠的绝对 2 个
百分点滑动窗口；官方百分比每前进 1% 都会把最新窗口纳入实时平滑值并更新预测。数据不足时显示“数据收集中”，估算区间跨过阈值时显示“额度
待确认”。所有金额均为本地 Token 按模型单价换算的 API 等值估算，不是官方美元余额
或实际账单。详情中的美元趋势图左上角汇总范围累计 API 等值，图形按模型展示非累计
时间桶峰形；1h、5h、今天、本周、本月都会裁掉首笔真实用量前的大段空白，
并按比例保留一小段零用量基线（约 5 分钟、30 分钟、1 小时、12 小时、2 天），
所以能看到从 0 开始上升；也可悬停和导出 CSV。
曲线下方的模型星系与上方共用同一组时间范围及“实时额度 / 本轮监测”选择，不重复放按钮。
模型星系采用左侧宏伟星轨主视觉、右侧模型占比与 Token / API 等值明细。浅色外观使用白色星空画布，深色外观使用深空画布；没有用量时显示与主题一致的专属空态。中央星球大小固定，放大的多层轨道按错相节奏轻微呼吸。每个有用量模型独占一条 360° 完整星轨，星轨本身用于完整展示模型，不用弧长表达占比；真实 Token 占比只在悬停信息和右侧明细中显示。同一星轨使用协调的同色系渐变、星尘和大气辉光，每环只有一颗连续运行的彗星，并默认突出 Token 最多的模型。它可区分 gpt-5.6-sol、terra、luna、
gpt-5.5 等日志模型，并列出本地用量记录数、Token 和 API 等值费用。
不同模型会按各自的官方标准短/长上下文单价分别换算；该图只读本地日志，不会
额外调用模型或消耗 Token。
本地用量采用增量日志索引。首次建立后只解析新增或发生变化的 JSONL 内容；打开额度页时会先显示上次快照，再在后台同步新记录，避免每次重新通读全部历史。索引只保存在本机 .cache，损坏时会自动重建，不会修改聊天记录。
账号分组展开或收起时会固定预留右侧窄滚动槽；滚轮按需隐藏，卡片宽度不会跳动。
所有页面顶部使用同尺寸星空横幅，展示 4 条错峰运行的动态流星、4 条远景流星和呼吸星芒；窗口失焦或最小化后暂停动画。页面切换和从任务栏恢复时保持任务栏图标及布局稳定。
额度球在 0% 和 100% 时仍保留轻量粒子、星环和大气辉光，但没有全幅扫描光；液位与数值保持固定。

常见问题
--------
1. 双击没反应：先确认 ZIP 已完整解压，不要在压缩软件预览页运行。如仍被拦截，
   右键 ZIP 选“属性→解除锁定”后重新解压。启动器会自动处理 ExecutionPolicy 和
   下载阻止标记，不需要管理员权限。
2. 安装失败：命令窗口会保持打开并弹出中文错误框。把错误框中的日志文件发给
   分享者排查；安装日志不包含账号 Token。
3. 找不到 Codex++：使用“Codex 启动”，或先安装 Codex++。
4. Codex++ 启动失败或出现管理员窗口：在“系统配置”中执行一次“修复 Codex++
   隐藏启动任务”，接受一次 UAC；以后不会重复弹出管理员 PowerShell。
5. 文字显示不全：适当拉宽或拉高窗口，然后正常关闭；下次会沿用该尺寸。
6. 额度没有数据：先用对应账号自然聊天；软件不会为了造数据调用模型。
7. SmartScreen 拦截：先核对分享者提供的 ZIP SHA-256，再选择“更多信息→仍要运行”。

卸载
----
可以在 Windows“设置 → 应用 → 已安装的应用”中卸载，也可以运行安装目录中的
“卸载 Codex Account Manager.cmd”。卸载程序默认保留账号列表、额度记录和设置，
避免误删；确认不再需要时再手动删除安装目录。账号凭据目录不会被卸载程序删除。

隐私说明
--------
本安装包不包含制作者的账号、Access Token、API Key、聊天记录、额度记录或本机路径。
请勿把自己安装使用后产生的 accounts.json、auth.json 或凭据目录分享给别人。
