# Codex Account Manager 使用说明

这是一款 Windows 账号与额度管理工具。安装包默认不包含制作者的账号、Token、API Key、聊天记录或本机路径。

## 一键安装

1. 完整解压 ZIP，不要直接在压缩软件预览窗口中运行。
2. 双击 `一键安装 Codex Account Manager.cmd`。
3. 安装完成后，软件会自动打开，并创建桌面和开始菜单快捷方式。

双击后会立即出现蓝色进度窗口，完成或失败都会弹出中文结果框。安装日志保存在 `%LOCALAPPDATA%\CodexAccountManager\InstallerLogs`，结果框也会显示本次日志的完整路径。

默认安装目录：`%LOCALAPPDATA%\Programs\CodexAccountManager`

支持 Windows 10/11 x64；主程序是自包含的 Windows x64 单文件，安装和运行都不需要另外安装 .NET 10，也不需要管理员权限。首次窗口会按制作者当前使用的 `1038 × 615` 尺寸居中打开，此后自动记住你最后关闭时的窗口大小和位置。

程序没有商业代码签名证书。Windows 首次运行若显示 SmartScreen，请先确认压缩包来源和 SHA-256，再选择“更多信息 → 仍要运行”。

## 添加和启动账号

1. 打开“账号切换”，点击“新增账号”。
2. 每个账号使用独立的凭据目录，防止凭据互相覆盖；聊天记录仍由共享 Codex 目录统一管理。
3. 每张账号卡提供两种桌面启动方式：
   - `Codex++ 启动`：电脑已安装 Codex++ 时使用。
   - `Codex 启动`：没有 Codex++ 时直接使用官方 Codex。
4. 当前正在使用的账号会标记为“当前账号”，并排在对应账号分类最前面。

真正切换账号时，软件会先投放目标凭据，再重新打开所选客户端；重复启动当前账号会直接复用已有凭据。

API Key 与 Access Token 账号都采用一键凭据投放：点击启动时，管理器会把所选账号的密钥写成官方 Codex App 可识别的 `auth_mode=apikey` 登录文件；无需在 App 内重复输入。Access Token 的模型请求仍经本机 PAT 网关使用月额度，已有 ChatGPT OAuth 会先备份但不是启动前置条件。

通过管理器的“Codex 启动”打开 PAT/API 账号后，Standard/Fast 选择器显示在官方 Codex 内。它是版本锁定的非官方本地兼容层，不修改已签名安装文件；实际 Fast/`priority` 是否受端点支持及如何计费仍由服务端决定。

“系统配置”中的代理地址和端口可分别编辑；地址默认 `127.0.0.1`。“自动检测”只探测本机回环监听，并把检测到的 HTTP 代理端口显示、回填和保存。本地 PAT 网关默认随软件启动，也可在这里手动打开或关闭。

“系统配置”还提供模型与价格表。“通过代理检查官网”会读取官方模型目录与价格，成功后按最新模型优先更新本地价格；失败时保留当前设置。价格可以手动调整，也可以恢复安装包内置值；下次官网检查成功后仍以官网结果为准。

`Codex++ 启动`会先快速确认隐藏启动任务，再在后台等待增强桥接完成，不再让 Account Manager 卡住一两分钟；Codex++ 的管理中间窗会保持隐藏。Codex App 自身的冷启动时间仍会受电脑性能、首次更新和杀毒软件扫描影响。

## 额度与用量

- 额度详情中的被动监测需要手动点击“开启额度监测”。
- 每次开启都会从点击时刻创建一个新的监测周期；关闭后不再更新推断，再次开启不会沿用旧周期的正常/异常判断。
- 监测只读取此后自然聊天产生的本地 Token 日志和官方整数百分比，不会发送测试提示、不会压力测试、不会为了测额调用模型，也不会轮询其他账号。
- 有 5h 窗口的周额度账号按 5h 窗口判断，正常参考阈值为 API 等值 `$10`；只有周窗口的账号按周窗口判断，阈值为 `$90`；月额度账号按最近有效窗口的主模型判断，Sol / Terra / Luna 阈值分别为 `$200` / `$100` / `$80`，未知模型回退到 `$200`。
- 监测采用重叠的绝对 2 个百分点滑动窗口；官方百分比每前进 1%，都会把最新窗口纳入实时平滑值并立即更新推测总量与剩余量。金额是按模型 API 单价换算的估算值，不是官方美元余额或实际账单。
- 美元趋势图可切换 1h、5h、今天、本周、本月：左上角是范围累计 API 等值，图中是按模型分色的非累计时间桶用量峰形，“今天”细分为 15 分钟数据点。五个范围都会裁掉首笔真实用量之前的大段空白，同时按比例保留一小段零用量基线（依次约 5 分钟、30 分钟、1 小时、12 小时、2 天），因此可以看清从 0 开始上升；此后的空白时间桶仍保留。悬停会显示各模型金额、时段速率和近 1 小时用量，也可导出 UTF-8 CSV。
- 曲线下方的模型星系与上方共用同一组 1h、5h、今天、本周、本月及“实时额度 / 本轮监测”选择，不设重复按钮。星系区域采用左侧宏伟星轨主视觉、右侧模型占比与 Token / API 等值明细；浅色外观使用白色星空画布，深色外观使用深空画布，没有用量时显示与主题一致的专属空态。中央星球大小固定，放大的多层轨道按错相节奏轻微呼吸；每个有用量模型独占一条 360° 完整行星环，环长只用于完整展示模型，不表达真实占比，精确占比会在悬停信息和右侧明细中显示。同一环使用协调而清晰的同色系渐变，不同模型采用可区分的独立色系。每条环只有一颗沿轨道连续运行的彗星，并配有星尘与大气辉光；动画使用轻量局部更新，窗口失焦或最小化后暂停。默认突出 Token 最多的模型；它支持 gpt-5.6-sol、terra、luna、gpt-5.5 等模型，只读取本地日志，不会额外调用模型。
- 本地用量使用增量日志索引。首次建立索引后，只解析新增或发生变化的 JSONL 内容；进入额度页时会优先展示上次快照，再在后台同步新记录，因此不会在每次打开页面时重新通读全部聊天历史。索引只保存在本机 `.cache`，损坏时可自动重建，不会修改原始聊天记录。
- 额度仪表改为“额度星球”，百分比仍只决定液位，不改变原有额度语义。星球使用前后分层的土星环、大气辉光、云纹、星尘与少量气泡营造层次，并删除全幅扫描光和横向扫描线；动画只做局部重绘，窗口失焦或最小化后暂停，0% 或 100% 时液位和数值保持固定，装饰动画不会改变推断结果。
- 账号分组收起或展开时右侧始终预留同一条窄滚动槽；滚轮按需隐藏，卡片不会随之横向跳动。
- 所有页面顶部使用同尺寸星空横幅，且不再显示账号数量徽章。横幅展示 4 条错峰运行的动态流星、4 条远景流星和呼吸星芒；窗口失焦或最小化后暂停动画。
- 页面切换和从任务栏恢复时复用已有界面，不会触发整页重建、临时隐藏任务栏图标、先显示错误的窄布局或短暂露出白色背景。
- 支持的模型会按各自的输入、缓存输入、缓存写入、输出及长上下文价格分别换算；金额仍是 API 等值估算，不是订阅套餐的官方美元余额或实际账单。

## 更新与卸载

- 自动更新：程序会显示安装包下载进度，完成 SHA-256 校验后在当前目录升级并自动重启；失败时重新打开原版本并保留更新日志。
- 升级：解压新版安装包并再次运行一键安装脚本，会保留已有账号、设置和本地额度记录。
- 卸载：在 Windows“设置 → 应用 → 已安装的应用”中卸载，或运行安装目录中的 `卸载 Codex Account Manager.cmd`。
- 为避免误删，卸载默认保留账号列表、设置和额度记录；账号凭据目录也不会被自动删除。

## 常见问题

- 双击安装文件没有反应：先确认 ZIP 已完整解压，再右键 ZIP 选“属性 → 解除锁定”后重新解压。也可右键 `一键安装 Codex Account Manager.cmd` 选“打开”；新启动器会自动处理 ExecutionPolicy 和下载阻止标记，不需要管理员权限。
- 安装失败：命令窗口会保持打开，同时弹出中文错误框。请把错误框中的日志文件发给分享者；日志不包含账号 Token。

- 找不到 Codex++：使用卡片上的 `Codex 启动`，或先安装 Codex++。
- Codex++ 启动失败或弹出管理员窗口：在“系统配置”中手动执行一次“修复 Codex++ 隐藏启动任务”，接受一次 UAC；以后切号不会再打开管理员 PowerShell。仍失败时可改用 `Codex 启动`。
- Codex 冷启动仍较慢：先确认 Codex 和 Codex++ 已更新，等待 Windows 首次扫描完成；重复启动当前账号会复用现有凭据，不会重复退出登录。启动诊断只记录在本机，不包含 Token。
- 切号后账号没有变化：先完全退出旧 Codex，再点目标卡片；确认每个账号使用不同凭据目录，并在账号详情检查凭据状态。
- 按钮或文字显示不完整：拉宽或拉高窗口；软件会记住最后一次关闭时的窗口大小。若 Windows 缩放比例很高，可重新打开软件让 DPI 布局刷新。
- 额度一直显示“数据收集中”：需要在开启监测后自然使用，并跨越足够的官方整数百分比层级。
- 趋势图没有数据：它只读取本机自然使用日志；刚安装、刚切号或尚未在该账号聊天时属于正常情况。
- SmartScreen 或杀毒软件拦截：先核对分享者提供的 ZIP SHA-256，再选择“更多信息 → 仍要运行”；不要关闭全局安全防护。

请勿分享自己安装后生成的 `accounts.json`、`auth.json`、API Key、Token、`%USERPROFILE%\.codex`、账号凭据目录或整个开发项目文件夹；只能分享这一个经过隐私扫描的一键安装 ZIP。
