# Codex Account Manager 便携版

这是一个不包含任何账号、Token、登录凭据或聊天记录的干净便携包。

## 使用方法

1. 完整解压压缩包，不要直接在压缩包内运行。
2. 双击 `CodexAccountManager.exe`。
3. 点击“新增账号”，为每个账号设置不同的凭据目录。
4. 聊天记录默认保存在你自己电脑的 `%USERPROFILE%\.codex`，不会写入本便携包。

程序已经包含 Windows x64 Codex CLI 运行组件。每张账号卡都提供“Codex++ 启动”和“Codex 启动”；没有安装 Codex++ 时可直接选择官方 Codex。

API Key 与 Access Token 账号都采用一键凭据投放：点击启动时，管理器会把所选账号的密钥写成官方 Codex App 可识别的 `auth_mode=apikey` 登录文件。Access Token 的模型请求仍经本机 PAT 网关使用月额度；无需在 App 内重复输入密钥，已有 ChatGPT OAuth 会先备份但不是启动前置条件。

系统配置把代理拆成地址和端口。地址默认 `127.0.0.1`；“自动检测”只探测本机回环监听并显示检测到的 HTTP 代理端口，手动编辑后可改用其它地址或端口。

额度页面显示本地 Token 用量、官方百分比和重置时间。额度推断需要在详情页手动开启；每次开启从点击时刻建立全新周期，关闭后停止更新，再次开启不会继承旧周期判断。软件不会发送测试提示、不会进行压力测试，也不会轮询或登录其它账号。

有 5h 窗口的周额度账号按 5h 主窗口判断，正常阈值为 `$10`；只有周窗口的账号按周窗口判断，阈值为 `$90`；月额度账号阈值为 `$200`。监测使用最近绝对 2 个百分点的实时滑动窗口；数据不足时显示“数据收集中”，估算区间跨过阈值时显示“额度待确认”。这些金额是本地 Token 按模型单价换算的 API 等值估算，不是官方美元余额或实际账单。

趋势图的 1h、5h、今天、本周、本月都会裁掉首笔真实用量前的大段空白，并保留一小段零用量基线；模型分布让每个有用量模型独占一条 360° 完整星轨，星轨不用弧长表达占比，真实 Token 占比在圆心悬停信息和下方明细显示。同一星轨使用协调的同色系渐变、星尘和大气辉光，每环只有一颗连续运行的彗星。额度球没有全幅扫描光，在 0%/100% 时仍保留轻量装饰动画，但数值固定。

请只使用你本人有权使用的账号、Access Token 或 API Key，不要分享登录凭据。
