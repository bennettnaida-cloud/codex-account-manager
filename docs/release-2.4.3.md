# 2.4.3

Windows 稳定性、本地网关连接管理、代理侧栏与界面流畅度更新：

- 修复原生代理节点（VLESS/VMess/Trojan/SS/Hysteria2）使用随机盐密文去重导致重复导入的问题，改用持久化 SHA-256 指纹并在读取时兼容回填旧节点；修复代理配置读取失败状态粘滞及批量测速覆盖禁用节点的问题，改为原子合并探测结果。
- 加固 `appsettings.json` 读取与保存流程：损坏配置自动备份并阻止启动/退出逻辑静默覆写为空配置；原子写入覆盖账号凭据与配置保存路径，并自动裁剪聊天分组同步历史备份。
- 修复额度轮换在已确认耗尽且重置时间未到时的状态回跳，以及账号删除顺序与残留代理绑定、轮换路由及会话粘性的清理；调整兼容 API 启动前模型探测总超时至 24 秒。
- 优化本地 PAT 网关与代理核心资源管理：复用回环连接池、限制并回收上游客户端与身份缓存、退出时等待在途请求收敛；将代理核心探测与启动移出全局锁并限制子进程输出缓冲。
- 改进代理侧栏高亮对比度、节点状态文案、主题对话框缩放与校验反馈，释放窗口关闭时的侧栏与额度锁资源，降低最小化轮询与界面重绘开销并清理冗余代码。
- 保留 2.4.2 兼容 API 默认模型 `gpt-6.1-sol`、2.4.1 聊天分组同步修复、CPA fill-first 调度、10%／3% 保留线及账号删除重加后的额度与用量隔离。

发布执行既有完整自检、启动、聊天分组、导入、模型及网关回归，以及安装包隐私扫描与隔离安装验证。

以上修复与优化适用于 Windows。macOS 本次仅同步发布版本号并执行独立构建验证。

本地构建更新桌面和任务栏快捷方式，不自动关闭正在运行的管理器、网关或 Codex 客户端。方便时自行重开管理器即可使用新版。
