# 2.3.35：自动同步可选模型

旧版定时任务只更新计价目录；Codex 的可选目录还依赖安装包中的逐模型模板。因此上游已经提供新模型时，桌面选择器仍可能缺少它。

- 管理器启动时及运行期间每 15 分钟，按各账号配置的网络获取兼容 API `/models`。账号启动前仍会刷新；关闭价格自动更新不影响模型发现。管理器未运行时没有后台定时任务，下次启动会重新同步。
- 每个账号的可选范围只来自其上游。启用“内置兼容模型目录”的账号继续显式合并内置范围。共享的是模型描述，账号白名单独立保存。
- 从 OpenAI Codex 官方仓库获取模型描述，至少间隔 15 分钟刷新并持久化。请求不携带账号密钥。优先使用官方描述，再用内置描述；尚无描述的新 GPT 推理/代码模型采用保守后备（32K、文本输入、不声明推理档位或 Fast 支持）。后续获得官方描述后自动替换。图像、音频、实时、嵌入及内部模型不加入编码选择器。
- 内置 GPT-6.1-Sol 和 GPT-6-Luna 描述。官方源暂时不可达时仍能发现上游新模型。不会因 401、超时、损坏响应或无可用模型的列表清空已有目录；发布响应前重新验证账号地址、密钥和配置，拒绝过期结果。
- 保留用户自定义 `model_catalog_json` 和所选默认模型。更新目录不会自动切换正在使用的模型，也不会重启正在工作的 Codex。已打开的 Codex 可能缓存目录，需要重新启动后显示新增项。

## 来源

- 官方描述：[openai/codex models.json](https://github.com/openai/codex/blob/main/codex-rs/models-manager/models.json)。内置的 6.1-Sol、6-Luna 及后备基础提示词于 2026-09-30 获取。
- 后备描述参考官方 [model_info_from_slug](https://github.com/openai/codex/blob/main/codex-rs/models-manager/src/model_info.rs)，并缩小上下文与能力声明。

## 验证方法

`Build-CodexAccountManager.ps1` 执行 Release 发布、完整 `--self-test` 和快捷方式回归。`tools/Test-AutomaticModelCatalog.cjs` 使用本机 HTTP 服务及假密钥验证新模型、官方/后备描述、失败保留、跨账号隔离、配置和凭据变化时拒绝过期响应、用户自定义目录与默认模型保留。传入 Codex 可执行文件后还验证真实 app-server `model/list`，不发送推理请求。

2026-09-30 本地验收：Release 构建、完整 self-test、快捷方式回归和上述 HTTP 故障用例通过；Codex 0.158.0 能读取当前账号自动生成的 18 项目录，包含 GPT-6.1-Sol。管理器启动日志确认两个兼容账号均完成自动同步。升级前后账号文件、密钥、默认模型和网关进程保持一致。另用隔离目录实测：同一 app-server 的第二次 `model/list` 不读取修改后的静态目录，因此已打开的客户端需要重启。

发布前复核：随安装包固定提供的 Codex CLI 0.154.0 通过完整自动模型目录回归及真实 `model/list` 检查。`--startup-self-test` 通过，覆盖两个入口、导航、进程身份、并发、日志就绪、可选补丁与侧栏兼容性；这些专项自检不代表在其他电脑上进行了交互实测。

## 安装与限制

版本为 **2.3.35**，继续使用兼容的 **8341** 网关及既有路由状态；本次不改变网关协议。安装到独立的 2.3.35 目录。新管理器可接管已有网关而不中断当前请求。

模型能否实际调用取决于账号上游。未知模型的后备能力是保守默认值，不代表已经验证全部功能。官方目录地址或 Codex 元数据格式将来改变时，保留本地后备并记录刷新失败，仍可能需要后续兼容性升级。
