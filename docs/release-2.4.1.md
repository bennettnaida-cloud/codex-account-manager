# 2.4.1

将本地 2.3.58.1 的更新正式发布为 2.4.1，统一程序显示、安装包、自动更新清单及 macOS 包版本号。

Windows 聊天分组同步修复：

- 同时识别旧版全局侧栏状态与新版 `electron-owner-atoms:` 所有者状态，兼容两种结构并存。
- 同步分组、排序、折叠状态与聊天归属时，保留各所有者和账号的身份及独立设置；仅更新所有者容器内已有的账号条目，不凭账号 ID 推测所有者或创建跨所有者条目。
- 区分“无法读取官方分组”与“官方分组确认为空”。数据库缺失、表或必要字段不兼容时，不将已有分组误当作已删除；有效空表仍正常同步真实删除。
- 保留状态备份、重复同步幂等性和未知结构保护，增加独立的聊天分组同步自检入口并接入发布验证。

继续保留 2.3.58 的账号删除重加隔离、CPA fill-first 调度、5h 剩余 ≤10%／仅周额度剩余 ≤3% 保留线，以及既有模型、导入和代理功能。

验证覆盖所有者容器、旧新状态并存、账号身份与设置隔离、未知结构、缺失数据库和表、缺失必要字段、有效空分组及重复同步，并执行既有完整自检与安装包验证。

以上功能修复适用于 Windows。macOS 本次仅同步发布版本号，仍通过独立构建与安装验证，不包含上述 Windows 专属改动。

本地构建更新快捷方式，不自动关闭管理器、网关或 Codex 客户端。正在运行的旧进程保持原版本，方便时自行重开管理器即可使用新版。发布包不包含用户账号、凭据或聊天记录。
