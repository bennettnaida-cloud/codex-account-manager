# 2.3.47

- 移除“新增账号”登录方式中的网页版 Session 选项、Session JSON 输入区、网页地址和独立编辑/更新窗口。
- JSON/ZIP 文件导入不再接受网页 Session 或旧版 Session auth.json，明确提示改用“通过 ChatGPT 登录（官方）”。继续支持 sub2api、CPA、官方 OAuth auth.json、PAT 和兼容 API。
- 已导入的 Session 账号、凭据目录和相关数据原样保留，显示“已停用”，不自动删除或转换。启动、模型测试、额度查询和网关轮换不再接受这类凭据；可通过新增账号完成官方登录后自行删除旧记录。
- 网关协议更新为 v16，保留读取旧网关状态的兼容性；升级不主动终止正在运行的管理器、网关或 Codex。重新启动新版管理器后，在安全边界应用网关升级。
- 保留 API Provider 等输入行的动态布局、按钮文字宽度适配、本地中转空页面兼容、启动前模型同步、逐账号代理，以及 5h 剩余 ≤10% / 仅周额度剩余 ≤3% 的轮换规则。
- Windows 和 macOS 版本号为 2.3.47，内置 Codex CLI 保持 0.163.0；macOS 本次仅同步版本号。

验证包括旧 Session 文件及嵌套格式拒绝、批量导入失败无部分写入、旧数据保留、凭据不误判成 PAT、启动/额度/模型测试提前停止，以及网关轮换和重复记录的停用检查。延续完整程序、账号表单布局、模型发现、启动和中转兼容回归；测试使用隔离数据和本机模拟服务，不发送用户真实模型请求。
