# 2.4.5

Windows 界面视觉、滚动流畅度与本地网关大请求兼容更新（包含未单独发布的 2.4.4 本地改动）：

- 主界面改为全画布宇宙星空背景：深色星空、星云、极光带、多层星光与流星覆盖标题栏、卡片间隙与状态栏，三套主题（极光浅色、深海夜色、星云夜色）分别配色；背景按窗口尺寸缓存并在关闭时释放全部绘图资源。
- 标题栏收紧为 68px 单行布局、状态栏 30px，同屏可显示更多账号；滚动改为平滑滚动并统一深色滚动条。
- 账号、轮换与代理侧栏卡片改为半透明圆角玻璃，消除卡片外侧 1px 直角描边残影。
- 修复本地 PAT 网关在大请求时被上游返回 HTTP 413 Payload Too Large 的问题：官方 ChatGPT 请求在未改写时保留原始 `zstd`／`gzip` 压缩字节与 `Content-Encoding`，改写后按原编码重新压缩，未压缩的大请求（≥ 256 KiB）自动使用 `zstd` 压缩；兼容 API 默认保持未压缩以兼容旧中转。
- 收到 413 时同账号透明重试压缩请求（`zstd`，被拒绝 `400`／`415` 时回退 `gzip`），仍失败则原样返回上游 413 响应。网关轮换协议升级为 `request-boundary-v19`，并兼容在线的 v18 网关平滑升级。
- 保留 2.4.3 代理节点指纹去重、配置防覆写与网关连接池优化，2.4.2 兼容 API 默认模型 `gpt-6.1-sol`、2.4.1 聊天分组同步修复、CPA fill-first 调度、10%／3% 保留线及账号删除重加后的额度与用量隔离。

发布执行既有完整自检、启动、聊天分组、导入、模型及网关回归（新增 413 压缩重试回环测试），以及安装包隐私扫描与隔离安装验证。

以上修复与优化适用于 Windows。macOS 本次仅同步发布版本号并执行独立构建验证。

本地构建更新桌面和任务栏快捷方式，不自动关闭正在运行的管理器、网关或 Codex 客户端。方便时自行重开管理器即可使用新版。
