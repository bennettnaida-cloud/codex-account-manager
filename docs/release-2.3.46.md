# 2.3.46

- 网页版 Session 导入整合到“新增账号 → 登录方式 → 网页版 Session（JSON 导入）”，直接在表单内打开 Session 网页、粘贴 JSON 并确认导入；移除顶部重复的 Session 按钮，保留文件导入入口。
- Session 名称可留空沿用邮箱；目录沿用导入器自动创建的独立目录，保留到期校验、重复凭据跳过和敏感字段最小化。切换登录类型时清空已粘贴的 Session 数据。
- 底部“导入 Session”按钮按照字体、文字长度和当前布局比例计算宽度，避免沿用“保存账号”的固定宽度而截成省略号。
- 独立 Session 编辑弹窗使用明确的百分比列宽和可换行提示，按钮独立固定在内容区域下方，避免内容的首选宽度把按钮挤出窗口。原有同工作区更新和仅修改名称功能保留。
- API 的 Provider、Wire API、Base URL、Model 依次跟随凭据提示卡实际高度排列，修复长账号目录及显示缩放导致 Provider 被提示卡遮挡的问题。
- 延续 2.3.45 本地中转兼容、模型同步、文件导入、代理及轮换功能。macOS 仅同步版本号；内置 Codex CLI 为 0.163.0。

验证：完整程序自测包含 Session 模式切换与解析、100%/150%/200% 布局、确认按钮文字宽度和 API 输入行不重叠检查。已通过隔离预览检查 API 行与 Session 编辑按钮；最终按钮宽度调整使用布局测量回归验证。所有预览均不保存真实账号或提交真实 Session。
