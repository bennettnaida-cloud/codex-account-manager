# 2.4.2

Windows 新增兼容 API 账号时，Model 默认值从 `gpt-5.5` 改为 `gpt-6.1-sol`。

- 新增账号窗口、账号记录默认值、空模型字段归一化、未指定模型的文件导入及配置生成使用同一个默认值，避免界面和实际配置不一致。
- 已有账号或导入文件明确指定的模型继续保留；未指定模型的导入账号仍在启动前发现上游模型，其他账号继续执行既有模型目录刷新与核验流程。
- 保留 2.4.1 聊天分组同步修复、CPA fill-first 调度、10%／3% 保留线及账号删除重加后的额度与用量隔离。

发布执行既有完整自检、启动、聊天分组、导入、模型及网关回归，以及安装包隐私扫描与隔离安装验证。

以上默认模型修改适用于 Windows。macOS 本次仅同步发布版本号并执行独立构建验证。

本地构建更新桌面和任务栏快捷方式，不自动关闭正在运行的管理器、网关或 Codex 客户端。方便时自行重开管理器即可使用新版。
