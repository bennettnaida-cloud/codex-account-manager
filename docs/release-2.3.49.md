# 2.3.49

- 修复新版 Codex 的“无法加载工作空间设置”：OAuth 开启网关轮换时，仅转发模型请求，不再写入指向 HTTP 回环网关的 `chatgpt_base_url`。该设置会被新版客户端拒绝并报 `workspace backend must use an HTTPS origin without credentials`，随后工作空间相关请求反复失败。
- 修复 PAT/兼容 API 搭配官方 OAuth 的双登录工作空间配置；模型凭据与工作空间身份继续分离。独立 PAT 的账号接口桥接保持原行为。
- 启动时清理旧配置中残留的工作空间回环地址，保持模型网关、轮换和服务档位配置；重复投放保持幂等。
- 保留 Windows 本机与 WSL 的手动选择，不强制改变默认主机，也不删除 WSL 连接或项目。
- 包含此前本地 2.3.48 的 Sub2API OAuth 刷新时间修复：保留真实 last_refresh，缺失时使用 JWT 的 iat，不虚构当前刷新时间，不更改 Token 或工作区。
- 未修改 Codex 渲染器或清空聊天数据。本次修复消除工作空间请求持续失败的配置原因；界面闪烁的完整验证需在用户重启并切换账号后进行。真正的服务端 overloaded 响应不等同于此本地配置错误。

验证：OAuth 直连／轮换切换、旧地址迁移、双登录身份分离、重复配置投放、导入凭据保持、启动和模型目录回归。内置 CLI 0.163.0；macOS 仅同步版本号。
