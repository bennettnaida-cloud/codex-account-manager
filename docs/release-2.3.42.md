# 2.3.42 — 网页版 Session 导入

## Windows

- 新增账号窗口提供“网页版 Session”入口。先在浏览器登录 ChatGPT，打开 `https://chatgpt.com/api/auth/session`，复制完整 JSON 到导入窗口；名称可留空并使用邮箱。
- 原有文件导入同时识别 Session JSON、数组及 ZIP 中的 JSON，提供预览、凭据去重和独立账号目录。
- 保存账号所需的 accessToken、工作区 ID 和有效期，不保存 Cookie、整份用户资料，也不制造 OAuth id_token/refresh_token。JWT 到期时间与 Session expires 取较早者；拒绝过期、缺少工作区、重复字段或身份矛盾的输入。JWT 解析仅用于本地结构检查，实际权限仍由上游在线验证。
- Session 经本地网关转发，固定工作区，使用该账号的代理和轮换设置。每次启动先在线获取模型，失效或无权限时明确提示，不切换当前客户端。额度查询使用内置 Codex CLI 0.163.0 的临时外部令牌认证，不改写磁盘凭据；该协议有版本依赖，原生 CLI 回归测试随发布执行。
- 账号提供“更新 Session”及名称编辑。更新只接受同一工作区，保留目录和设置；不同工作区需另增账号。Session 无 refresh_token，不能自动续期，到期需重新导入。
- 网关协议增至 v14，新增 Session 工作区绑定和过期检查；旧网关仍可服务原账号，Session 需新版网关。升级不主动中断当前任务。

保留 2.3.41 的 OAuth/PAT/API 启动模型同步、sub2api/CPA 文件导入，以及 5h 剩余 ≤10%、仅周额度剩余 ≤3% 的轮换规则。Session 上游须允许 Codex 访问，不保证所有浏览器登录账号均有权限。

## 验证

包含 Session 解析、脱敏/过期/矛盾输入、目录隔离、重复导入、同工作区更新、网关工作区绑定、轮换凭据、在线模型查询，以及真实 Codex CLI 在本地模拟服务上的令牌/额度协议和磁盘凭据保留测试；延续完整应用、模型、启动与轮换自测。

macOS 仅同步发布版本，保留现有功能，本次 Windows Session 导入尚未移植。
