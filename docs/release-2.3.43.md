# 2.3.43

修复导入 OAuth 账号后模型测试成功、额度仍“待识别”的兼容性故障。导入凭据可能缺少 CLI 文件认证所依赖的刷新时间；额度 RPC 因而可能不携带 Authorization，最终返回 401，尽管原访问令牌有效。

额度辅助进程现在使用官方 app-server 的 chatgptAuthTokens 接口，在内存中绑定所选账号现有且有效的访问令牌及工作区。无需再次网页登录，也不编造 last_refresh 或重写原令牌。校验令牌有效期及工作区一致性，过期令牌保留既有原生 OAuth 刷新流程。模型请求、主客户端和运行中的网关不受影响。测试成功而后续额度读取失败时，弹窗显示脱敏后的具体原因。

验证包括缺少 last_refresh、令牌过期及工作区不匹配的自测，已有协议解析及网关保护自测；真实账号只执行额度只读 RPC，不重复发送模型测试，也不消耗重置卡。
