# 2.3.13

修复通过本地网关使用 GPT-6（`gpt-6-astra`）时出现的 “The model requires a newer version of Codex” 错误。

- 网关转发客户端的 `originator`、`User-Agent` 和 `version`，避免将新客户端错误标识为旧版；缺失或过旧的版本信息使用 0.153.4 兼容值。
- Windows 安装包内置 Codex CLI 0.153.4。
- 新增 GPT-6 官方价格；输入、缓存输入、输出分别为 $10、$1、$50 / 百万 token，缓存写入 1.25 倍；超过 272K 输入后按官网长上下文费率计算。
- 模型价格支持启动后后台检查、每 6 小时自动更新，以及随时手动检查。网络失败保留已保存的价格；自动刷新不更换用户选择的默认模型。
- 此版本使用 8333 端口，支持与旧版网关并存完成更新。
- 修复主动测试 OAuth 账号时被误判为双登录凭据混用的问题。测试请求需通过本地签名验证并匹配所选账号，不影响当前会话的轮换路由。

在管理器中检查更新，或从 GitHub 的 `latest` Release 下载 Windows 安装包。完成更新后重新启动管理器和 Codex，确认使用新版网关。账号或 API 服务需要具备 GPT-6 使用权限。

本次 GPT-6 修复不新增双登录行为，也不调整 2.3.11 的目录栏和分类行为。
