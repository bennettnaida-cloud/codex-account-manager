# 2.4.8

Windows 系统配置与模型价格页重构、官方价格解析修复、额度展示去噪及浅色主题提亮更新（包含未单独发布的 2.4.6–2.4.7 本地改动）：

- 系统配置与模型价格页重构（2.4.6）：统一卡片式视觉布局，优化配置项层级、模型价格表展示及手动编辑与恢复内置值体验。
- 官方 OpenAI 定价解析修复与 16 模型目录更新（2.4.6）：支持解析最新官方定价页的 11 列（Standard／Flex／Priority）与 4 列 Markdown 表格，避免抓取漏项；内置 `assets/model-catalog.json` 扩展至 16 个模型，新增 `gpt-6.2-sol`、`gpt-6.2-astra`、`gpt-6.1-sol`、`gpt-6.1-terra`、`gpt-6-sol`、`gpt-6-luna`，默认模型更新为 `gpt-6.1-sol`。
- 被动额度展示去噪（2.4.7）：移除被动额度估算中的 `额度异常`／`额度正常` 判定标签与异常区间高亮，保留冷静直观的 `推测剩余 $X / $Y`、首次估算进度以及趋势图表与 CSV 导出。
- 浅色主题提亮与深色文字区避让（2.4.8）：`极光浅色` 改为明亮通透的柔彩极光画布、`青瓷浅色` 改为清透青瓷画布，搭配亮色磨砂顶栏／状态栏、深色清晰文字、纯白浮动卡片及浅色滚动条；深色宇宙星空主题（`深海夜色`、`星云夜色`）保持不变并增加文字区星芒避让，避免星光落在标题或状态栏文字上。
- 保留 2.4.5 全画布宇宙星空背景、68px 紧凑单行顶栏、平滑滚动与本地网关 HTTP 413 压缩重试（`request-boundary-v19`，兼容在线 v18 网关），以及 2.4.3 代理节点指纹去重、配置防覆写、网关连接池优化、2.4.1 聊天分组同步修复、CPA fill-first 调度、10%／3% 保留线及账号删除重加后的额度与用量隔离。

发布执行既有完整自检、启动、聊天分组、导入、模型及网关回归，以及安装包隐私扫描与隔离安装验证。

以上界面与解析改动适用于 Windows。macOS 本次同步发布版本号、共享模型价格目录及对应单元测试，并执行独立构建与安装验证。

本地构建更新桌面和任务栏快捷方式，不自动关闭正在运行的管理器、网关或 Codex 客户端。方便时自行重开管理器即可使用新版。
